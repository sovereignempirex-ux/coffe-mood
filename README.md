## 🌟 نظرة عامة | Overview

**Mood Café** هو تطبيق متطور لإدارة وتجربة المقاهي والكافيهات الراقية يجمع بين الجمال البصري الفاخر (Glassmorphism & Gold Theme) والخفة الفائقة (Ultra-Lightweight) ليعمل بسلاسة تامة حتى على أضعف الهواتف الاقتصادية دون أي بطء أو استهلاك زائد للبطارية والذاكرة.

يتميز التطبيق بمحرك صوتي تفاعلي مُبتكر مبني بالكامل عبر **توليد الترددات الرياضية (PCM Synthesis)** بدون الحاجة لملفات صوتية ثقيلة، بالإضافة إلى **عجلة حظ المزاج (Mood Roulette)**، ونظام **تتبع مباشر للطلبات (Live Order Tracking)**، ومحرك تخصيص دقيق للمشروبات (درجة السكر، نوع الحليب، الثلج، الإضافات).

---

## 🚀 المميزات الرئيسية | Core Features

### ⚡ 1. وضع الأداء الفائق للأجهزة الضعيفة (Lite Mode)
- **مفتاح فوري بنقرة واحدة (⚡)** في الشريط العلوي لتشغيل أو إيقاف الرسومات الثقيلة.
- تعطيل الحسابات الرياضية للموجات ثلاثية الأبعاد وتحويل الخلفية إلى تدرج لوني ثابت فخم ومريح للعين.
- تقليل استخدام المعالج (CPU) ومعالج الرسوميات (GPU) بأكثر من 85% للحفاظ على عمر البطارية وسرعة الاستجابة.

### 🔊 2. محرك الصوت التفاعلي الخفيف (PCM Sound Engine)
- مؤثرات صوتية نقية يتم توليدها لحظياً في الذاكرة عبر موجات جيبية (Sine Waves) بنظام `AudioTrack`.
- أصوات واقعية لكل حدث داخل التطبيق:
  - 🔘 **Click FX:** نقرة خفيفة للأزرار.
  - 🛒 **Pop FX:** صوت إضافة مشروب للسلة.
  - 🎲 **Tick / Roulette FX:** دوران عجلة الحظ مع تصاعد السرعة.
  - 🏆 **Fanfare Win:** نغمة احتفالية عند الفوز بمشروب.
  - 🚀 **Checkout Whoosh:** صوت مميز عند إتمام الطلب وتجهيز رسالة الواتساب.
  - 🗑️ **Trash Sweep:** صوت مسح وحذف المنتجات.

### 🎲 3. عجلة حظ المزاج (Mood Drink Roulette)
- محتار تشرب إيه اليوم؟ بضغطة زر، تدور عجلة الحظ بتأثيرات بصرية وصوتية ممتعة لتختار لك مشروبك المثالي حسب مزاجك.
- إمكانية إضافة المشروب الفائز مباشرة إلى السلة أو تخصيصه فوراً.

### 📱 4. تخصيص المشروبات وسلة الطلبات المتقدمة
- اختيار الحجم (صغير 250ml، وسط 350ml، كبير 500ml).
- تخصيص كامل: مستوى السكر (سادة، مضبوط، زيادة)، نوع الحليب (عادي، شوفان، خالي اللاكتوز)، درجة البرودة والإضافات.
- ملخص السلة وحساب الإجمالي تلقائياً مع خيار الطلب الفوري عبر واتساب ورسائل منسقة واحترافية.

### 📍 5. نظام تتبع الطلبات الحي (Live Order Tracking)
- متابعة مسار وحالة الطلب خطوة بخطوة من الاستلام، للتحضير بواسطة الباريستا، وحتى الاستلام أو التوصيل مع مؤقت تقديري.

### 👑 6. ركن الطرب الأصيل ولوحة الإدارة
- استعراض نجوم الزمن الجميل وأشهر مقولاتهم (أم كلثوم، فيروز، عبد الحليم، فريد الأطرش).
- لوحة إدارة متكاملة (Admin Dashboard) لإدارة الأصناف، الأسعار، الإحصائيات، ومتابعة الطلبات.

## 🏗️ الهيكلية التقنية | Architecture & Tech Stack

```
com.example/
├── data/
│   ├── local/            # Room Database & Pre-populated Menu Data
│   └── model/            # Data Models (Product, CartItem, Order, User, Settings)
├── ui/
│   ├── components/       # Reusable Glassmorphic UI & Dialogs
│   │   ├── CafeWorld3DCanvas.kt      # Dual-mode Canvas (Dynamic 3D vs Static Lite)
│   │   ├── GlassComponents.kt        # M3 Cards, Glowing Badges, Buttons
│   │   ├── MoodRouletteDialog.kt     # Interactive Roulette Feature
│   │   └── OrderTrackingDialog.kt    # Live Order Timeline Visualizer
│   ├── screens/          # Main UI Screens
│   │   ├── HomeScreen.kt             # Menu, Hero, Audio & Lite toggles, Filters
│   │   ├── ProductDetailModal.kt     # Deep Customizer Modal
│   │   ├── CartSheet.kt              # Bottom Sheet Checkout
│   │   ├── UserProfileScreen.kt      # Account, Orders History, Favorites
│   │   └── AdminDashboardScreen.kt   # Management & Analytics
│   ├── sound/
│   │   └── MoodSoundManager.kt       # Lightweight PCM Synthesizer
│   ├── theme/            # Color Schemes, Typography, Shapes
│   └── viewmodel/
│       └── MoodCafeViewModel.kt      # Unified State Machine & Audio Coordinator
```

## 🛠️ كيفية التثبيت والتشغيل | Installation & Setup

1. **استنساخ المشروع (Clone Repository):**
   ```bash
   git clone https://github.com/your-username/mood-cafe.git
   cd mood-cafe
   ```

2. **فتح المشروع في Android Studio:**
   - افتح المجلد في **Android Studio Ladybug (أو أحدث)**.
   - سيقوم Gradle بمزامنة التبعيات تلقائياً عبر `libs.versions.toml`.

3. **البناء والتشغيل (Build & Run):**
   - اختر الجهاز المستهدف (أو محاكي Android 8.0+).
   - اضغط على **Run (Shift + F10)**.
