## ✦ About

**MOOD CAFÉ & TARAB** هو نظام مقهى رقمي تفاعلي مصمم ليجمع بين تجربة القهوة الفاخرة وروح الطرب العربي الأصيل داخل واجهة عصرية سريعة وخفيفة.

المشروع ليس مجرد Menu إلكتروني — إنه تجربة متكاملة تحتوي على:

- ☕ قائمة مشروبات تفاعلية
- 🛒 سلة طلبات متقدمة
- 🎲 Mood Drink Roulette
- 🧋 تخصيص المشروبات
- 📦 تتبع الطلبات
- 👤 حسابات المستخدمين
- 👑 لوحة تحكم للإدارة
- 🎵 تجربة طرب عربية
- ⚡ Lite Mode للأجهزة الضعيفة
- 🖥️ Desktop Application باستخدام Electron

---

## ✨ Core Experience

### ☕ Premium Café Menu

استعراض المنتجات بطريقة تفاعلية وفاخرة مع:

- صور المنتجات
- الأسعار والتصنيفات
- التفاصيل والإضافات
- الحالات التفاعلية
- Add to Cart animations

تم تصميم الـ UI حول هوية:  
**Dark Espresso × Luxury Gold × Glassmorphism**

---

### 🧋 Advanced Drink Customization

يمكن للمستخدم تخصيص مشروبه حسب الخيارات المتوفرة:

| الخيار | الوصف |
|--------|-------|
| الحجم | صغير / وسط / كبير |
| مستوى السكر | حسب الرغبة |
| نوع الحليب | كامل / خالي الدسم / نباتي |
| كمية الثلج | قليل / متوسط / كثير |
| الإضافات | إضافات متنوعة |

ويتم تحديث السعر والإجمالي تلقائيًا.

---

### 🎲 Mood Drink Roulette

> *«مش عارف تشرب إيه؟ خلي مزاجك يختار.»*

ميزة تفاعلية لاختيار مشروب عشوائي من القائمة:

```
START → SPIN → SUSPENSE → RESULT → CUSTOMIZE → ADD TO CART
```

تدعم التجربة مؤثرات صوتية وحركية خفيفة لزيادة الإحساس بالتفاعل.

---

### 🛒 Smart Cart

سلة الطلبات مصممة لتكون جزءًا من تجربة المستخدم:

- إضافة وإزالة المنتجات
- تعديل الكمية
- حساب الإجمالي
- تخصيص المنتجات
- Empty State
- Checkout وإرسال تفاصيل الطلب

---

### 📦 Order Tracking

متابعة حالة الطلب بشكل واضح وتفاعلي:

```
🟡 Order Received
       ↓
🟠 Preparing
       ↓
🔵 Quality Check
       ↓
🟢 Ready
       ↓
🟣 Completed
```

---

### 👤 User Experience

يوفر النظام مساحة للمستخدم لعرض:

- الاسم والبريد الإلكتروني والهاتف
- سجل الطلبات والطلبات السابقة
- البيانات الشخصية

يتم حفظ بيانات الجلسة محليًا باستخدام `localStorage`.

### 👑 Admin Dashboard

لوحة إدارة مخصصة لمتابعة وتشغيل النظام:

**الإحصائيات:**
- إجمالي الطلبات
- الطلبات المعلقة
- الإيرادات
- الطلبات المكتملة
- المنتجات والبيانات المتعلقة بها

**Order Management:**
- متابعة الطلبات الحالية
- إدارة البيانات المرتبطة

### 🎵 MOOD TARAB

جانب مميز من هوية المشروع — تم دمج أجواء الطرب العربي الأصيل مع التصميم الرقمي الحديث.

الهوية البصرية تستوحي عناصر من:
- المسارح القديمة والأسطوانات
- الراديو الكلاسيكي
- الإضاءة الدافئة والخشب الداكن والذهب
- أجواء المقاهي العربية

مع الحفاظ على أسلوب UI حديث.

### 🔊 Interactive Audio

نظام مؤثرات صوتية تفاعلية خفيفة:

| الحدث | الصوت |
|-------|-------|
| Button Click | Click FX |
| Add to Cart | Pop FX |
| Roulette | Tick FX |
| Winning Result | Fanfare |
| Checkout | Whoosh |
| Delete | Sweep |

الصوت جزء اختياري ويمكن تعطيله عند الحاجة.

---

### ⚡ Lite Mode

> *«Premium UI without sacrificing performance.»*

يوفر Lite Mode تجربة أخف للأجهزة الضعيفة. عند تفعيله يتم تقليل أو تعطيل:

- المؤثرات الثقيلة
- Animations غير الضرورية
- Blur المكثف
- Particles
- الحسابات الرسومية المستمرة

مع الحفاظ على الشكل العام للمشروع.

## 🚀 Installation

### 1. Clone
```bash
git clone https://github.com/your-username/mood-cafe.git
```

### 2. Enter the project
```bash
cd mood-cafe
```

### 3. Install dependencies
```bash
npm install
```

### 4. Start Desktop Version
```bash
npm start
```

## 🔐 Data Philosophy

المشروع يحافظ على بياناته الحالية وعدم كسر الـ Data Flow الموجود.

يتم استخدام `localStorage` في الأجزاء التي تعتمد على التخزين المحلي، مثل:
- `mood-user`
- `mood-orders`

يجب الحفاظ على الـ Keys الحالية عند تطوير المشروع لضمان عدم فقد البيانات المحلية.
